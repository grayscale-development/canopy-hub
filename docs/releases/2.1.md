# Canopy Hub 2.1

- Browse wiki sections and groups again, and filter their pages by tag.
- Restore an older version of a page in a pop-up that shows what changed. History is kept.
- Preview AI Update and AI Merge changes before you save them.
- Use the new ⋯ More menu on a page for Edit details, Move, Merge, and Archive.
- Editing tools stay hidden until Editor Mode is on.
- Clearer messages after saving, restoring, and merging, plus a warning before you leave with unsaved changes.
- Find future release updates in the new Release Notes area under Hub.
